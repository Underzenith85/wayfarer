# Current mental/spirit resistance attempts

The existing mental/spirit transition is a trusted, authored numerical provider.
There is no native campaign/player command host for it. This change adds an
explicit `apply_current_mental_use` system entry and `CurrentMentalChannel`; it
does not add a player generation flag or infer actor-derived scores.

The current provider applies B348's resistance exception: after the attack fails,
the subject need not roll. A missing supplied subject roll then produces the
shared failure-only receipt, with the actual attacker scoring triple, declared
subject resistance, Rule of16 applicability, and `affected=False`. It contains no
fabricated subject check. If the author supplies a real subject total as well,
the existing two-check receipt is retained; a failed attacker still cannot affect
the subject even when the nested ordinary contest names that attacker the winner.
A successful attack requires actual supplied subject scoring input.

These channel totals predate individual die receipts. Their canonical three-die
decomposition is scoring input only, not evidence of the original physical dice.
The provider draws no new attack/subject dice. Neutralize's existing critical
failure can still draw a real cooldown die from explicitly supplied authoritative
randomness; replay must receive that original randomness rather than invent it.

For current authored numerical contexts, B349's Rule of16 scope follows all
three declared facts: a resistance score is provided, the attack is supernatural,
and the subject is living or sapient. A definition-name whitelist cannot override
those declarations. Zero or negative provided resistance still counts as provided;
eligibility remains true when no numerical reduction is necessary. This does not
grant stock Medium, Oracle, Terror or another trait a new printed attack procedure.
The unversioned provider retains its historical five-name cap selection and bytes.

The current typed context permits strict signed scores. The voluntary final
attack must be at least3 after the actual existing concentration/control
adjustments and Rule of16 cap. Mandatory subject resistance, including1,0 or a
negative score, remains rollable. Admission and successful-attack missing-roll
validation occur before fatigue. The legacy control-score clamp remains in the
historical provider; current control adjustments retain the actual low score so
the voluntary floor cannot be evaded. Interrupting/stopping an existing effect
is not a new attack and does not acquire this floor.

Only `affected=True` admits knowledge, control, possession, or suppression effects.
Existing successful control/Neutralize branches narrow to the two-check receipt
before using its victory margin for duration. Failure-only receipts never enter
those branches. Current failure/success and the existing real cooldown, control,
world-knowledge and resource transitions still use the same native reducers.

A private optional event origin captures generation1, the exact original authored
current channel, complete command/digest, build revision and time BEFORE retry,
concentration or target-wary adjustments. A separate prepared snapshot records
those actual derived scores. Mind Control's penalty is supported by compact
prior native control-event IDs and exact payload digests, not recursive event
copies. Readers match immutable historical sources, verify controller/kind/effect,
chronology and exact raw-to-derived arithmetic, then reprepare through the common
current resistance scorer. They never query later active grants to reinterpret
an accepted original. Current records validate strict version,
command/channel/actor/target binding, event identity/time, duplicate events and
actual resistance replay. Reserved duplicate JSON keys are rejected before model
decoding, including duplicate facts inside the separately encoded command/raw/
prepared contexts. An explicit null origin is invalid; only true field absence
selects historical behavior. Required current context/attempt pairs cannot be
removed while retaining a current origin. An accepted exact retry returns its receipt before
fresh context lookup; a changed current command identity cannot reuse that ID.

`replay_mental_use` accepts the actual recorded native resource event. Generation1
replays from its captured original context and exact command/build binding, then
compares the regenerated full event and outcome. It does not read state_after or
query a fresh resolver. Historical absence requires explicitly supplied historical
channels; missing historical context is unsupported, not reconstructed from the
new default. The original unversioned `apply_mental_use` retains its requirement
for both supplied rolls and rejects a current context as a way to relax the old
score bounds. Old channel schema and exact native event bytes have independent
frozen-primary SHA regression oracles.

These are pure system-provider witnesses, not database/transport or physical-dice
claims. Whole B348 section evidence and other callers are coordinated separately;
this patch does not promote a capability, section, source audit or broad trait
procedure. Authored scores and channel eligibility remain authoritative provider
inputs rather than newly inferred character/biology facts.
