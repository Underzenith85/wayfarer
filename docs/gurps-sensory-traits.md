# GURPS sensory and communication traits

The optional `package:gurps-basic-sensory-traits@1.0.0` package publishes the
32 Basic Set senses and communication entries as pinned compiler definitions.
Variable Detect rarity, Scanning Sense mode, Telecommunication medium,
Speak With Animals scope, and zero-cost racial sense variants are priced from
trusted choices rather than caller arithmetic.

Approved builds project darkness, magnification, hearing range, camouflage,
silence, protected-sense, and communication capabilities. Active observation
and communication use authored channels that bind the actor, target, location,
medium, and revealable fact IDs. The reducer checks actor authority and
compare-and-set revision, records blocked and resisted outcomes, reveals only
channel facts, and replays an identical command ID without repeating effects.

Inventory entries retain #191 until the selected-printing source baseline is
reconciled; #234 is removed only as an implementation blocker.
