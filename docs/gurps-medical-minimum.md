# Voluntary medical checks below effective skill 3

Selected Campaigns fourth printing B345 defines effective skill after modifiers
and forbids attempting a nondefense success roll below 3. B424 supplies the
medical treatment rolls. This bounded #830 follow-up applies that admission to
the existing exact Basic Set First Aid, Physician, resuscitation, stabilization
and lasting-injury Surgery hosts. It does not promote medicine certification.

Fresh eligible BeginRecovery commands capture an independent strict private
generation and the trusted CareEnvironment actually used. The private wrapper
retains the exact original public input, including whitespace. Unknown/coerced
versions, duplicate private keys, malformed environment fields and changed
original intent refuse. CareEnvironment has one shared lower-level schema;
its existing orchestration import and serialized fields remain available.

For First Aid and Physician, the actual final target is known before the external
environment callback. Source admission checks it there, after existing actor,
presence and default-knowledge gates, and rechecks under the command lock.
Environment-dependent procedures use the existing native treatment adjustments
before reserving a task or selecting dice. The same canonical check arguments
serve admission and the eventual roll. A raw Surgery default of 2 can therefore
receive the printed TL7 equipment bonus of 1 and lawfully roll at 3; TL6's zero
bonus leaves it inadmissible.

An accepted source task records an authenticated private marker binding its
producer, actor, patient, start, deadline, procedure and captured score. Completion
uses that task's generation and captured skill, independently of current defaults
or configuration. Current condition modifiers still apply before its first roll.
If those make the check unavailable at the deadline, the existing interrupted
settlement path commits no original roll, healing or complication roll. It keeps
elapsed time, earlier health rolls and other committed effects. A narrowly bound
state invariant permits this exact deadline interruption only for a settled task
with its authenticated source marker. Unmarked historical tasks and rest retain
their previous timeline invariant. Authored genesis cannot supply the marker;
player campaign and stream projections omit it.

Historical absent-generation producers retain their original input bytes and
pending skill snapshots. A fresh completion of an old skill-2 task retains its
old roll and consequences. New captured starts support original-genesis seeded
reexecution without a live environment resolver. Old unmarked care starts never
captured their external environment and remain unsupported for original-start
seed reexecution; tests reexecute those continuations from their genuine retained
pending producer checkpoint, without fabricating missing source observations.

SQLite and PostgreSQL cases cover source First Aid 2 refusal, final 3 healing,
paid skills, exact retries and public-input duplicates, real alcohol HT rolls
making a current target 3 become 2, conservation at interruption, actual lasting
injury shortening, strict metadata/provenance, privacy, genesis and both replay
directions. Mandatory natural HT 2 still selects its existing health roll.

Rest, FP recovery, bandaging, drugs, unconsciousness/source knockout recovery,
natural healing and mandatory survival checks do not acquire this skill floor.
Trauma maintenance's mandatory choice between patient HT and Physician remains
separate. Provider capability changes, continuous invasive work, partial surgical
consequences and wider care modifiers remain outside this slice. The existing
native invasive host selects its treatment consequences at the final roll; this
change does not invent partial injuries, refunds or complications before that
original. Full medicine and #830 remain open.
