# Initial Great Haste Step before casting

This bounded #980 consumer adds private `initial-step-great-haste` generation six
and `named-initial-step-great-haste` generation seven. Both admit only `start`.
Campaigns B366 permits a Step with Concentrate; B368 derives Step from current
Move and permits movement before the action. Characters B236 puts the spell roll
at the end of the final Concentrate and ends that opportunity on the roll.
Accordingly this carrier completes its initial movement before the first casting
action and never appends movement after a spell roll.

The canonical mover supplies the full authoritative Step allowance, path,
occupancy, terrain and current movement restrictions. There is no invented two-yard
cap: tests prove approved Move11/20 two-yard and Move21 three-yard initial movement,
and refusal above actual allowance. The caster's first subjective Concentrate is
credited once after movement. Native ATR opportunities and shared clock settlement
remain canonical; segment movement does not create an extra action.

A Wait stores the accepted prefix and remaining path in the existing private
casting lease. A restarted resume completes only that remainder before creating
the first casting second, preserving named subject identity when selected. Current
range/visibility is bound at the casting pose; later target movement refreshes the
actual final check. Existing current source, ownership, approval, authority and
geometry checks apply, with atomic rollback on insufficient entropy or invalid
movement. Private leases and command generations do not appear in player views.

Recorded generations one through five are unchanged. Existing generation-four and
five Steps remain bounded to one yard, and ongoing casting retains the B237 ritual
base skill15 threshold, adjusted only by low mana. A new initial command cannot be
used as a later Concentrate. Continuation uses the existing one-yard plain/named
carrier. Initial movement before casting starts is distinct from ongoing ritual
movement; this change does not supply larger ongoing, after-action or split Steps,
cross-encounter targets, or the remaining Apportation carriers. #980 remains open.

Tests cover plain/named actual paid casts on SQLite and PostgreSQL, current moved
subject numeric range, success/failure FP, invalid path before RNG, authority,
stale inputs, exact retry/restart, private projection, Wait remainder, full seeded
command reexecution and strict generation/carrier pairing. No public schema changes
or source-certification promotion are included.

The pre-movement source lease defers sight only inside the authenticated new
initial-carrier binding context. It still verifies current approved builds,
channel and subject identity, energy commitment and authority. The context ends
before movement; actual first casting runs the ordinary final-pose sight checks.
Tests prove plain unseen-to-visible admission, visible-to-unseen full rollback,
both-unseen plain refusal, and named known-subject unseen −5. Recorded bounded
Steps do not acquire this deferral. Generations six/seven additionally require
the complete existing authenticated original-input metadata; absent or partial
metadata is refused rather than interpreted as an old command.
