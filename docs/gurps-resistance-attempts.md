# Source-current B348 resistance attempts

This bounded Basic Set correction adds the source-permitted failed-attack path
without requiring an unattempted subject roll. It does not prohibit an actual
optional resistance roll after failure. It does not certify all supernatural
advantages, spell procedures, B345 consumers, or the whole success-roll capability.
The selected source is Campaigns fourth printing B348, including Margin of
Victory and Resistance Rolls; B345 supplies voluntary attack admission and B349
supplies the existing Rule of16 calculation.

`engine.rules.resistance_attempts` prepares the actual declared contestants and
cap before entropy. A voluntary attacker below effective3 cannot attempt the
roll. A mandatory subject at1 or a negative modified score still rolls normally.
A failed current attack retains its original CheckTrace, both declared
contestants and cap applicability in `FailedResistanceAttempt`; there is no
fabricated subject CheckTrace or contest winner. A successful attacker uses the
existing ResistanceTrace with both actual checks. The supplied-roll adapter also
accepts an optional actual subject roll after failure. Both branches are
re-scored against captured producer preparation before a current receipt is
trusted. Actual dice must be exactly three integer d6 per attempted roll.

The old `gurps_checks.resistance_roll`, receipt shape and historical replay remain
unchanged. A nested ordinary contest can name the failed attacker as winner when
both fail; `.affected` correctly remainsFalse. Current effects use `.affected`,
not that nested winner. Recorded optional rolls are not relabeled source-illegal.

## Native AbilityService

Fresh resisted activation captures independent private
`ability_resistance_attempt_generation:1`, retaining the exact original input
beneath the private envelope. It is separate from Rule16, off-shift, Symptoms and
Common Knowledge policies. No player command flag is added. A private native
activation origin binds the initiating command, actual effect identity, build and
interval. A delayed resolve inherits that producer's0/1 policy; a fresh command
cannot silently enroll an old concentration. Accepted originals and exact retries
are retained.

The canonical current attack preparation is shared between admission before
injury/exertion/FP and the actual roll. Mind Reading uses its existing captured
activation shock, range, current retry and condition rules. Delayed resolve checks
its still-unrolled current score before any new distraction or health dice.
Native condition changes from3 to2 leave prior activation cost/time and pending
concentration intact; native cancel remains available. The existing off-shift
minimum is retained independently.

Current AbilityEvent stores its full actual receipt and preparation, omitting
both fields for historical data. Its current read boundary validates re-scoring,
participant identity, actual check suffix, critical/failed/outcome flags and
absence of damage/disclosure/active effects on failure. Current native JSON and
activation origins retain their writer's exact encoding, rejecting duplicate or
partial policy metadata. Ordinary legacy event bytes have a captured regression
golden. Current activation origins and Creature/Mental native execution receipts
cannot be authored into campaign genesis.

## Trusted system providers

Creature and mental/spirit providers have explicit source-current system entry
points and recorded-origin replay adapters. Their existing unversioned entry
points retain historical defaults and old receipt bytes. They are canonical
system APIs, not newly invented player orchestration hosts. See
`gurps-creature-resistance-attempts.md` and `gurps-mental-resistance-attempts.md` for
their precise supported authoritative contexts and legacy boundaries.

Creature current receipts retain private producer generation and preparation
without changing ordinary command payload digests. Mental current receipts retain
the original authored current channel and actual derived preparation, including
causal control adjustment proof. A supplied optional subject roll is legal only
when the captured authored context actually supplies it. Replays use the saved
producer origin and context; they do not infer policy from Rule16 flags or invent
historical source context.

failures, both kinds of tie, all three victory-margin formulas, typed current
modifiers and critical outcomes without a separate winner override. The native
unarmed matrix uses honest actual inputs, including raw14/13 with canonical−2

Actual AbilityService cases cover failed-attack three-die receipts, subject ties,
actual damage/thought effects, mandatoryWill1, deferred producer inheritance,

separate native cases demonstrate full command reexecution.

Source-case audit records and exact section execution bindings are deliberately
