# Staged minimum effective skill

Fresh Basic Set staged Inspect/Social producers apply Campaigns B345 to the final
prepared effective target before exertion, action costs, elapsed time, or original
dice. They prepare again after actual clock consequences. Unrolled secret checks
carry the producer's independent private minimum-skill generation; selecting a new
response never upgrades an older pending opportunity.

Fresh long-task producers reject an impossible current worker check before the
shift. A separate supervisor must currently have a lawful skill check before its
possible critical-success +2 can contribute to this intake bound. This bound
predicts no future condition or prerequisite outcome. Every actual voluntary skill
phase is refreshed and admitted immediately before its original dice. Mandatory
B346 overtime HT remains legal below effective HT 3.

When selected supervisor overtime makes supervision unlawful, no supervision roll
or failure is invented. A private unavailable-supervision record preserves that
selected HT and FP/Luck effects; the worker's mandatory overtime check remains due.
The worker receives no supervision bonus. If the actual worker check is then
unlawful, the shift ends interrupted with no work credit. Elapsed time, selected
consequences, and the private daily work reservation remain committed. Interruptions
after elapsed time but before the first original retain a separate spent-shift
reservation without pretending a check was selected.

These private records cannot be authored at genesis or exposed through player
state/event projections. Generation absence retains historical serialized pending
records and roll ordering. This slice does not certify other success-roll consumers
or claim full Basic Set compliance.
