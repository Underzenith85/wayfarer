# Cinematic technology consumers

Source: selected Basic Set Characters third printing, B168, B184 and B228.

Computer Hacking/TL requires an approved Computer Programming purchase and a learned TL. The trusted system declares its TL, reachable actors and information. Successful access creates private access; subsequent find and change operations learn or change actual system facts. A critical failure records incriminating intrusion evidence. Neither source declares a universal FP cost or duration, so these are not invented. Invalid targets and unauthorized requests fail before dice; durable receipts prevent repeated effects or dice on exact retries.

Weird Science aids an actual authored invention attempt: +5 ordinary invention, +1 Gadgeteer, or +2 analysis of weird technology. The aid is consumed by its matching project phase and work item. Critical success records the additional insight awaiting GM interpretation. Critical failure blocks project work until an authorized, receipted GM resolution records its spectacular consequence; no universal injury is fabricated. Source-derived IQ technological TL penalties are shared with the mundane technology procedure consumer; other controlling attributes retain one point per TL.

These are engine consumers. Transport/UI integration and end-to-end compliance gates remain open. General investigations beyond authored invention analysis and the content of critical-success insights still require GM interpretation. This change does not promote rule certification or claim universal compliance for these skills.
