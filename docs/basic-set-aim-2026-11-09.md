## The bounded timing repair

Actual Basic equipment includes a heavy blaster with a fixed +4 scope. Its scope
bonus requires four seconds of Aim, but the existing duration counter capped at
three seconds, making that bonus unreachable. A separate
[elapsed-time field](../src/wayfarer/engine/simulation/combat/maneuvers.py) now
tracks full time for the exact Basic profile under the recorded
`scope-aim-elapsed` feature. The ordinary extra-Aim bonus still caps at +2 and the
existing ordinary duration counter still caps at three. The
[transition rules](../src/wayfarer/engine/simulation/combat/maneuver_transitions.py)
and [carry/reset rules](../src/wayfarer/engine/simulation/combat/turn_commitment.py)
use the same recorded boundary. Default zero is omitted from state serialization.

The actual ready, owned TL11 heavy-blaster sequence reaches Aim bonuses
10, 11, 12, 16 and 16 over one through five seconds. The scope's +4 first appears
at second four, while ordinary extra Aim stays capped. An actual subsequent
attack with purchased skill 12 uses target 28. The new feature is recorded in the
accepted command input, including its durable persistence allowlist. Commands
without that feature retain historical semantics, ignore the new elapsed field
and preserve the old Aim bonus 12 after four seconds. Adopting historical state
uses only the known old capped duration; unknown earlier elapsed time is not
reconstructed.
