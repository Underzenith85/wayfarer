# Current Basic Set defaults require actual GM knowledge

The current private producer generation is 2. An unpaid default in an actual
Basic Set actor host needs genuine GM evidence that the skill is known in the
actor's society, including when the actor has never adopted the earlier policy.
Absence means unknown and refuses the attempt; it does not write a negative fact,
adopt the actor, choose a society or change an approval. The existing trusted,
seated GM producer supplies real positive or negative observations.

The independent command and originating-policy versions have these meanings:

| Version | Admission |
| --- | --- |
| Absent / 0 | Retained historical default behavior |
| 1 | Retained optional-adoption behavior; adopted actors use their GM facts |
| 2 | Current actor defaults require genuine societal eligibility |

Metadata accepts exact integers, verifies retained digests and original input
bytes, and rejects future versions. Current commands do not rewrite old command
inputs. Combat/Wait, queued checks, rulings and secret-task preparations capture
their own version; a later responder cannot replace that origin with its fresh
setting. A captured original or Luck choice retains its numerical inputs. A new
defender's eligibility remains independent of a legacy attacker's policy.

Purchased skills retain their levels and default credit without societal setup.
Known=true supplies no missing default edge, training, prerequisite, UB payment,
TL or package permission. Raw construction compilation remains arithmetic, not a
claim that a live actor may attempt every listed default. Source-current player
skill views omit unavailable unpaid defaults; activation never creates GM facts.

Ordinary Inspect/Social checks, actor-sheet combat/NPC consumers, the handwritten
Innate Attack fallback, staged paid missiles, task/queue/ruling origins, direct
Medical and the [native physical/care joins](gurps-default-knowledge-native-fallbacks.md)
use the current policy. Missing facts refuse before the relevant new default's
entropy/costs. Existing daily outcomes and accepted hazard/care task snapshots
keep their captured numbers. Independent HT swimming fatigue and actual falling
injury still occur when an optional skill contribution is unavailable.

## Existing specialized GM proof

`DeclareArmouryTraining` already records actual GM societal knowledge, alongside
current approved-build revision and verified TL. Generation 2 consumes that valid
proof rather than demanding a duplicate generic adoption/positive observation.
It validates its identity, owner, time, supported skill set and current approval.

Generic explicit observations and the latest valid specialized positive proof
are read in authoritative event order. The last explicit assertion among the
currently valid proofs decides a skill. Replacing a specialized training snapshot
expires its older snapshot, preserving that source's existing latest-record
contract. An empty generic baseline or an omitted specialized skill is unknown,
not an explicit false assertion. Generic false after specialized true denies a
new attempt; specialized true after generic false restores it. Generic true can
supply the societal fact while separate current specialized TL/training evidence
remains required. No replacement observations are written.

Selection and repair start retain their existing current-authority and physical
revalidation. A selected plan stays immutable for its start ID; it cannot grant
permission against a later contrary fact before the original begins. Once work
has started, accepted skill/parts/original context remains captured through later
fact changes. Current physical custody and item linkage still apply.

## Exact B344 witnesses and remaining scope

The native source cases use actual pinned definitions: Lockpicking IQ10→5 and
IQ25→15, Interrogation max(IQ12−5, Intimidation14−3, Psychology13−4)=11, and
Intimidation24→Interrogation21 without a skill-source cap. Their ordinary native
rolls, real disclosure, retries and original-genesis seed reexecution distinguish
the actual targets. Unadopted current attempts refuse until real GM facts exist.
Canonical Alchemy/Karate/spell No Default and learned-skill invariance remain
separate from societal familiarity. These witnesses do not implement the whole
Lockpicking, Interrogation or Alchemy procedures.

Trusted numerical kernels, including standalone `SkillCompiler` arithmetic and
`apply_composed_attack` without a live actor API, do not independently claim a GM
eligibility join. Production composed use goes through the actual checked actor
host. A directly authored numeric `SocialContext.target`/`skill_level` is likewise
a trusted scenario numeric contract; the ordinary and NPC actor-derived routes
are the live default consumers covered here. The separate passive healing
Physician threshold still has only a provisional Veterinary-default witness,
not a newly claimed host fix. No automatic social biography inference exists.

This implementation does not promote the full skill_defaults capability, every
skill description, B173 chapter or B344 section. Exact section evidence and the
remaining entry-point classifications require independent review before any
source-ledger decision.
