# Rooted Feet execution

The private Rooted Feet command family admits a purchased, approved Basic Set
caster with skill 10–14, authenticated normal mana and the ordinary ritual. A
trusted physical observation binds one co-located, visible, touched hostile
standing human to its current body, approved build and world facts. Missing or
changed facts reject before dice, fatigue or elapsed time.

B244 specifies ST resistance, cost 3, no maintenance and a one-minute duration.
The actual command advances the canonical clock by one second. Ordinary casting
failure costs one FP; a resisted successful cast costs three FP; critical success
costs no FP and initially bypasses resistance. Critical failure costs three FP and
uses the existing canonical spell backfire consumer (B235–236, B241).

An active effect retains the original casting check. The subject may make one
ST−5 escape attempt in each genuine combat turn. Current ST includes the
canonical B426 fatigue reduction, rounded up, for both initial resistance and
later escape; the original casting check remains immutable. The repeated contest uses the
original casting dice and a fresh resistance roll; a tie releases the subject.
This composes B244’s explicit repeated resistance against the original roll with
B241 and B348–349 Quick Contest rules. The initial critical casting exception is
not reapplied as an automatic win in later escape contests. Current ST is halved,
rounding up, below one-third FP (B426), before
applying the escape −5. Voluntary escape at nonpositive FP is unsupported and
refuses before dice because the first carrier does not implement the required
Will check to continue exertion; involuntary initial resistance is not refused
solely for nonpositive FP. Exact retries retain
the result and a different command ID cannot buy another attempt in the same turn.

The pure consumer interface prevents locomotion while active, applies −2 to
supported melee weapon skills and halves supported Dodge, rounding down. Shared
runtime consumers must supply actual movement, attack, Feint, Parry and Dodge
proof; a private effect record or a reducer diagnostic alone certifies none of
those actions. Exact expiry belongs to canonical clock checkpoint settlement.

The first carrier excludes transformed or nonhuman anatomy, Magic Resistance,
other active spell carriers, unknown size, incompatible timed hazards and casting
during combat. Unresolved defense combinations and unclassified productive
Shield, Cloak or unarmed choices must be refused rather than assigned an invented
modifier. Ranged weapon skills receive no Rooted Feet penalty. These restrictions
are visible unverified variants, not claims that the printed spell forbids them.
Whole Body Control issue #779 also includes other named spells and remains open.

Focused actual-host tests cover the five casting outcomes, original ordinary and
critical roll escape contests, costs, time, persistence, authority, stale revision,
checkpoint rollback and restart/exact retry. Their backend parameters retain both
SQLite and PostgreSQL. The composed tests also execute actual weapon attacks, weapon Parry, plain Dodge,
Feint and a canonical thrown hatchet whose purchased ranged skill stays unchanged.
They fold and reexecute the full original genesis through all registered commands,
and prove active T59 and expired T60 effects. Actual locomotion consumers include
Move, Step, retreat, scene travel and physical movement.

The first Dodge carrier halves the canonical base score before roll modifiers and
refuses unsupported low-HP/FP, Haste, Combat Reflexes, posture, shield, height,
entangle and pending visibility or attention combinations before dice. Mapped
shield knockback from crushing melee or ranged impacts and Shield Rush against a
rooted target are explicit unsupported displacement compositions. These guards
leave source-uncertain variants visible instead of assigning invented physics.
