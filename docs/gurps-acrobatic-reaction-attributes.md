# Attribute reductions in Acrobatic Dodge

Campaigns fourth printing B375 requires the Acrobatics check before Dodge, substituting Aerobatics in flight. This check is part of the defensive reaction and does not consume a maneuver. B419 excludes shock from defensive reactions; B421 similarly excludes temporary attribute reductions from defensive reactions that require no maneuver. Ordinary skills governed by a lowered attribute still lose the corresponding amount.

The private `acrobatic-reaction-attributes` feature selects the existing defensive build projection for the preceding Acrobatic Dodge check. With purchased skill 8 and current Symptoms DX−4, a roll of 8 now succeeds against 8, granting Dodge +2. The previous ordinary projection checked against 4, granted Dodge −2 and caused 3 injury in the paired fixture. Ground Acrobatics and airborne Aerobatics have the same source-derived exemption. An ordinary governed skill still has target 4; a reaction roll of 9 still fails against 8 and gives Dodge −2.

This does not exempt all skill penalties. B428 explicitly distinguishes penalties to attributes, skills and active defenses. The change removes only temporary attribute reductions from this reaction projection. Purchased skill levels and trait bonuses, current ST and equipment consequences, visibility, injury, fatigue, maneuver restrictions and the once-per-turn limit retain their existing policies. Direct skill penalties require their own source-bound condition consumer and are not reclassified as attribute reductions here.

Direct combat commands and actual typed task defense producers capture the feature privately. Recorded absence preserves the old skill trace, defense, injury and exact command/dice replay. Public commands and schemas are unchanged. Tests cover both stores, authority and stale admission, entropy rollback, retry, event folding and seeded reexecution.

This bounded correction leaves issue #878 open. Aerial and swimming Dodge and Drop still lack selected concealment destination/altitude carriers; it does not claim those consumers from Aerobatics support or ground geometry.
