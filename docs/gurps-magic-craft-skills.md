# GURPS Basic Set magic-craft skills

Issue #243 accounts for Alchemy, Herb Lore, Ritual Magic, Symbol Drawing, and
Thaumatology. The package pins their attributes, difficulties, technological
markers, source defaults, prerequisites, required-specialty boundaries, and
allowed procedural modes to Characters B174-225.

The runtime resolves only bounded analyze, prepare, locate, identify, invoke,
inscription, and research checks. It requires an approved build, actor authority,
owned subject items where the procedure manipulates an object, compare-and-set
revision, and an explicit random source. Outcomes use the shared receipt ledger,
survive JSON restart, do not reroll on retry, and remain private to the actor and
GM. Recipe invention, ingredient economics, spirit behavior, and free-form
magical discoveries remain narrative or future catalog work.

Inventory rows remain `partial` pending source certification issue #191.
