# Rule of 16 in approved ability bindings

The B349 eligibility boundary is living **or** sapient, independent of a body's
shape. Fresh approved `burning-malediction` and `mind-reading` commands now bind
that fact from the approved target's base IQ and actual authoritative body,
through the same target-scope adapter as composed Malediction. Temporary IQ
penalties do not turn a sapient target into an ineligible object. Proven Unliving
IQ5 targets receive no cap; living IQ5 and Unliving IQ10 targets do. Ambiguous
low-IQ bodies refuse before native attack entropy or activation costs. Cancellation
and maintenance do not introduce a new resistance-scope check.

The existing caster score, target resistance and mandatory dice order are
unchanged. The scope selects only the existing canonical resistance reducer's
Rule-of-16 parameter. Mind Reading still applies its existing range, Mind Shield,
Psi Static, retry and authored-thought boundaries; this change does not certify
those entire abilities.

An independent private `ability_rule16_generation` is captured on fresh typed
ability execution. Historical unmarked commands retain their former unconditional
cap. Actual legacy `principal:<command JSON>` producers remain valid and can be
retried or reexecuted; only records whose committed family is exactly
`resource/ability` are normalized into the registered replay adapter. Unknown
versions, mismatched digests and unrecognized producers do not receive a permissive
fallback. No player command schema changes or authored target-scope booleans were
added.

Five manually source-bound host cases exercise burning pre-cap18 and Mind Reading
pre-cap20 against approved living/nonsapient, Unliving/nonsapient and sapient
Unliving targets. Each has a separate literal numeric oracle and independently
seeded source-genesis replay on SQLite and PostgreSQL. Historical raw producer
reexecution, existing ability regressions, refusal before entropy, and cancellation
of previously valid pending legacy uses cover the compatibility boundary. These
are explicit Rule16 host witnesses, not evidence that every supernatural ability
or unmodeled biology is implemented.
