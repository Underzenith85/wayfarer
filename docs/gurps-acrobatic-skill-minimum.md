# Acrobatic Dodge: preliminary success-roll eligibility

Selected Campaigns fourth-printing B345 forbids attempting a success roll below
effective skill 3, with an exception for actual active-defense rolls. B375
requires a separate Acrobatics roll before Dodge; its skill check receives the
ordinary success-roll minimum. The subsequent Dodge keeps the B374 exception,
including automatic success on 3 or 4 at defense scores below three.

The consumer computes the same final preliminary skill for admission and its
actual roll. Existing B174 purchased task bonuses and B361 direct skill
aftermath penalties each apply once. Existing B421 reaction exemptions remain
in force; temporary attribute loss is not reclassified as a direct skill
penalty. The existing purchased-skill requirement is unchanged.

An independently captured `acrobatic-skill-minimum` combat feature enrolls fresh
ordinary and typed defense commands. Historical absent flags keep their
recorded scores, draw order and receipts. Typed opponent-original preparation
does not predict an unselected defense: its legal original remains captured.
When the defender subsequently chooses Acrobatics, admission precedes any new
opponent Luck draws, including secret originals and rerolls. Refusal preserves
the original, pending choice, cooldown, HP and history. Choosing ordinary Dodge
continues through its native route.
Fresh typed defenses also capture the existing Acrobatic trait-bonus feature,
so a real Perfect Balance +1 can lawfully raise final2 to final3 before either
acceptance or Luck. Its historical omission retains the old typed score.

The native composed-defense service has an independent command envelope. Its
fresh commands capture only the four Acrobatic flags: the new minimum plus the
existing trait-bonus, reaction-attribute and direct-condition features needed
to calculate that same final skill. Other combat features are not enabled by
this join. The private allowlist rejects unrelated features, booleans, unknown
names and duplicates. Empty historical envelopes remain byte compatible.

Actual approved DX6 and one point in Acrobatics produce skill4. The existing
row-28 Fright producer and successful recovery produce the B361 skill−2
aftermath: final2 refuses before new dice. DX7 instead produces lawful final3;
DX6 with Perfect Balance also reaches 3 through its real +1 modifier. Controlled
seeds distinguish successful and failed skill checks, actual Dodge scores and
injury. Both SQLite and PostgreSQL cover exact retries and seed reexecution.
Actual Change Posture followed by source-produced stunning separately proves
ordinary Dodge1 can still succeed on 3.

This is a bounded B345/B375 eligibility correction. It does not add flight
authoring, terrain concealment, a new condition producer, default-skill
knowledge or movement facts. Aerial/swimming Drop, unsupported interposition
geometry and the remaining branches of issue #878 retain their existing
boundaries. No source section or certification status is promoted.

Evidence: `test_acrobatic_skill_minimum.py` and
`test_acrobatic_skill_composed.py`, with existing Acrobatic condition, trait,
attribute, optional-defense, feature and native composed-host regressions.
